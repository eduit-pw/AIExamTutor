# CKE Exam Sheets — Licensing Notice

This folder contains official CKE (Centralna Komisja Egzaminacyjna) exam PDFs
distributed with AI Exam Tutor under the **public-domain archival policy**
described in spec §0.2 and §2.2.

## Policy Summary

v1.0 ships only with CKE exams marked **archiwalne** (archival), i.e., older
exams that CKE has explicitly placed in the public domain or released under a
"free educational use" policy.

**We do NOT distribute recent exams (last 3 years).** The student must acquire
those themselves via CKE's official site or their school.

## Sources (example)

- `inf03_2022_archiwalne.pdf` — INF.03 May 2022 archival exam from CKE's
  `archiwalne` subdirectory, marked "materiały archiwalne dostępne do
  dowolnego wykorzystania" (archival materials available for any use).

## Adding new PDFs

Before adding any CKE PDF to the `resources/exam_sheets/` directory, verify:

1. The PDF is hosted in a CKE `archiwalne` folder.
2. The CKE webpage states "dostępne do dowolnego wykorzystania" (available for any use).
3. Update this `LICENSE_NOTICE.md` with the new file name, year, and source URL.

Failure to respect CKE's licensing could result in a takedown request.
